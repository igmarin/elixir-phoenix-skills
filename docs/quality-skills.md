# Quality skills

Use the smallest card that matches the task:

- `code-quality` for targeted Credo, formatter, and static-analysis work.
- `refactor-code` for behavior-preserving structure changes.
- `code-review` for a diff review.
- `respond-to-review` for evaluating and addressing reviewer feedback.
- `testing-essentials` for ExUnit patterns.

`elixir-essentials` owns the shared language baseline. Run project-configured checks; do not turn optional analysis or full-suite runs into gates for unrelated changes.
